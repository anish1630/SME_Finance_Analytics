# SME Financial Analysis Dashboard

## Project Overview
This project analyzes Small and Medium Enterprise (SME) financial transactions using Python, SQL Server, and Power BI. It helps understand business sales, expenses, and net profit through data analysis and interactive visualizations.

## Objectives
- Analyze business sales and expenses.
- Calculate net profit.
- Query and summarize financial data using SQL.
- Build a Power BI dashboard for financial insights.

## Tools & Technologies
- **Python** — Data analysis and calculations
- **Pandas** — Data processing
- **Microsoft SQL Server** — Data storage and SQL queries
- **Power BI** — Financial dashboard and visualization
- **Git & GitHub** — Version control

## How to Run
1. Clone or download this repository.
2. Install Python and the required packages.
3. Configure SQL Server and update connection settings as needed.
4. Run the Python analysis scripts from the `src` folder.
5. Open the `.pbix` file in Power BI Desktop to explore the dashboard.
